## Release rule

No country becomes GREEN merely because the app is technically available.

A country reaches launch readiness only when:
1. legal/status gate is resolved;
2. compensation is implementable and auditable;
3. protection/insurance gate is resolved;
4. data/geolocation notice is ready;
5. dispatch/algorithm register is ready;
6. deactivation/appeal route exists;
7. support/escalation ownership exists;
8. public Courier information is accurate;
9. Store/runtime readiness is confirmed;
10. qualified local review is complete.
